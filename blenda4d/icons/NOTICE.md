# Icons in this folder

These are Blender's own interface icons, recoloured for Blenda 4D's colour hierarchy:

- `<icon>__<group>.png`: Blender's icon SVGs from the Blender source (`release/datafiles/icons_svg/`, branch
  `blender-v5.2-release`), with the white fill changed to the group's colour.
- `ops.*__<group>.png`: Blender's tool icons (`release/datafiles/icons/*.dat`, as installed with Blender 5.2), with
  their accent colour changed.
- `sticky_uvs_disable__*.png`: Blender's `STICKY_UVS_DISABLE` icon (three scattered squares) redrawn with three
  different square sizes, for the Random Effector and Random Field.
- `axis_*__axis.png`: the X, Y and Z letters, drawn for Blenda 4D.
